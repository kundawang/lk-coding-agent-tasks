我们看图交流全靠嘴上说"左边那个角上"，效率太低。想让你做个网页版的标注工具：
在图上框重点、拉线量尺寸、写批注，然后把标注导出去。

一批已有标注和工具清单在 samples 里，格式 README 里有，别改。

要做的：矩形、多边形（多次点击闭合成形）、直线、文字标注；滚轮缩放、空格或中键平移；
选中标注能改颜色、改批注、删除；文字标注双击能就地编辑。
直线要显示长度——我给一个"比例尺"（多少像素等于一毫米），要能显示成实际尺寸。

两个重点：

一是坐标换算。所有坐标都是相对原图像素的，跟窗口大小、缩放级别、平移位置都无关。
同一个标注在 100% 和 400% 下拖出来的结果必须一致，导出的坐标也必须是原图坐标。
这个我最在意，以前的版本一缩放标注就飘。

二是导出能原样导回来，位置一丝不差。

还有：samples/annotations.json 里有两条坏数据（坐标越界、多边形只有一个点），
要单独把这两条报出来，其他标注照常加载，不能整份失败。

别引库、别 npm、别构建，原生 ES module + Canvas。README 里写清楚坐标变换怎么算的、
比例尺怎么用的、导出格式长什么样。
