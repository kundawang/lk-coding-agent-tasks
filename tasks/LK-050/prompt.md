我们做新项目配色，设计师给一张首页截图，我们从里面挑颜色，挑出来之后又发现文字对比度不够。
想让你做个从图片生成主题的工具。

生成规则在 samples/brand.json，格式 README 里有，别改。

要做的：把图丢进来，先做颜色量化把主要颜色抽出来，挑出主色（默认取饱和度最高的，
也可以改成取占比最大的），然后按主色生成一套中性灰阶（跟主色同色相的低饱和色，不是纯灰），
再调出深浅两套主题，最后导出 CSS 变量和 JSON。

两个重点：

一是对比度必须真的达标。规则里写了正文要 4.5、大字 3.0、边框 1.5，
生成完你要自己校验一遍并把结果列出来；有不达标的要明确标出来，别装作没这回事。

二是同一张图生成两次结果必须一样。颜色量化那一步不能受随机种子影响，
不然我每次刷新都是新配色，没法用。

还要顶住极端情况：全黑的截图、几乎单色的图、4000x3000 的大图（这个不能卡死界面，
可以先降采样再量化）。

界面上左边是图（能看量化的结果，比如把主色标在图上），右边是生成的主题预览和变量。

别引库、别 npm、别构建，原生 ES module + Canvas。README 里写清楚量化算法、主题是怎么生成的、
对比度怎么校验的。
