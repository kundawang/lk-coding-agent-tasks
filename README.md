# dragsort

多容器拖拽排序，网页版。一个是待办、一个是进行中，卡片能在两栏之间来回拖。

纯静态、无构建、无依赖。

## 目录

```
samples/board.json   两栏和里面的卡片
```

## 数据格式

```json
{
  "columns": [
    { "id": "todo", "name": "待办", "cards": [{ "id": "c-1", "title": "改接口" }] },
    { "id": "doing", "name": "进行中", "maxCards": 3, "cards": [] }
  ]
}
```

`maxCards` 是可选的容量上限。

## 要做的

- 卡在同一栏里上下拖、跨栏拖、拖到空白处放到末尾
- 拖的时候要有插入位置的提示，别让人猜
- 每一栏有容量上限时，拖满了要拒绝并提示
- 松手之后顺序/归属要持久化（localStorage 就行），刷新还在
- 撤销至少 30 步

## 重点

- **键盘也要能用**：空格拿起、方向键移动、空格放下、Esc 取消（拖拽不能用鼠标独占）
- **不能乱**：拖拽过程中要能滚动到看不见的位置（拖到视口边缘自动滚）
- 拖拽期间列表不能因为重排而抖动；放下的位置要和提示的位置**一致**（这条最容易做错）
- 数据里出现重复卡片 id 或者引用了不存在的栏，要报出来
