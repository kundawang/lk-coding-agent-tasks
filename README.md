# patchbench

补丁应用器，网页版。把 diff 打到一堆文件上，打不上去的地方要说清楚为什么。

纯静态、无构建、无依赖。

## 目录

```
samples/files/      要被修改的原始文件
samples/changes.patch  一个 unified diff，包含能打上的和打不上的
```

## diff 里会出现的东西

- 多个文件、新增文件、删除文件、重命名
- 每个 hunk 带上下文行与行号（`@@ -a,b +c,d @@`）
- 有的 hunk 上下文对不上（文件被人改过）
- 有的文件根本不存在
- 尾部有 `\ No newline at end of file`

## 输出

每个文件给一个结果：成功 / 部分成功 / 失败，失败的要说清是哪个 hunk、第几行、
期望的上下文是什么、实际读到的是什么。
