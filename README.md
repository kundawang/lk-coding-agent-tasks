# treeedit

树结构编辑器，网页版。节点能增删改、能拖拽换父级、能展开折叠，节点多了也不能卡。

纯静态、无构建、无依赖。

## 目录

```
samples/tree.json   一棵三千个节点的树
```

## 节点格式

```json
{
  "id": "n-1",
  "name": "根",
  "type": "folder",
  "children": [
    { "id": "n-2", "name": "子节点", "type": "file", "children": [] }
  ]
}
```

`type` 是 `folder` 或 `file`，`file` 不应该有子节点。

## 要做的

- 展开折叠、选中、重命名（就地编辑，回车确认、Esc 取消）
- 增删节点，删除有子节点的要二次确认
- **拖拽换父级**：拖到节点上变成它的子节点、拖到两个节点之间变成兄弟节点，位置要看得出来
- 键盘操作：上下移动、左右折叠展开、F2 改名、Delete 删除

## 要顶住的情况

- **拖拽不能造成环**：把一个节点拖到自己后代下面必须拒绝，并给出提示
- **三千节点不卡**：展开全部之后滚动、折叠、拖拽都要顺（该虚拟化就虚拟化）
- 导入一份坏数据（重复 id、file 带 children、children 不是数组）要报出**具体是哪个节点**的问题
- 撤销重做至少 50 步，拖拽、改名、删除都要能退
