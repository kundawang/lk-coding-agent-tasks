# hexscope

二进制文件解析与元数据查看器，网页版。把一个文件拖进来，左边十六进制、右边把结构解出来。

纯静态、无构建、无依赖。

## 目录

```
samples/sample.png   一张小 png
samples/record.bin   我们自己的一种记录格式
```

## 要能解出来的东西

**PNG**：8 字节签名 + 一串 chunk，每个 chunk 是 `长度(4) 类型(4) 数据 校验(4)`，
都要大端。至少把 `IHDR`（宽高、位深、颜色类型）、`IDAT`（压缩数据长度）、`IEND` 解出来。

**record.bin**：自定义格式，头部是魔数 `REC1`，然后 `版本(1) 记录数(2, 小端)`，
每条记录是 `时间戳(4, 小端) 长度(1) 名称(UTF-8) 值(4, 小端浮点)`。

两种格式的每一条都要能点，点了左边十六进制视图要跳到对应字节并高亮。
