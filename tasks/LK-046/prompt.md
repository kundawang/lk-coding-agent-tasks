我们文档站的存量内容都是 HTML，想迁到 Markdown 上去。找过在线的转换器，表格和代码块转得一塌糊涂。
想让你自己写一个。

几篇真实文章和期望结果放在 samples 里（articles 是输入，golden 是期望输出），格式 README 里有，别改。

要转的元素我列在 README 里了：标题、段落、粗斜体、行内码、代码块（带语言）、嵌套列表、
引用、链接图片、表格、分隔线、删除线。

几个最容易做砸的地方，我要你重点保证：

- 代码块里的内容原样保留（缩进、空行都不能动），内容里出现三个反引号时围栏要加长
- 表格要转成 Markdown 表格，单元格里的竖线要转义，表头缺失也要处理
- 嵌套列表的缩进要正确，有序列表起始序号不是 1 的要写出来
- 正文里的 Markdown 特殊字符要转义

验收方式是：把你转出来的 Markdown 再渲染回 HTML，跟原 HTML 的语义结构对得上——
标题层级、列表层级、链接地址、代码内容必须一致。

解析要自己写，不许引 html 解析库，也不许用 innerHTML 拼字符串。

界面上左边贴 HTML、右边出 Markdown，再加一个"结构对比"视图，我要看两边层级对不对得上。

别引库、别 npm、别构建，原生 ES module。README 里写清楚支持哪些元素、转义规则、验收怎么做的。
