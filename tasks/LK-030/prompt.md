我们编辑后台支持富文本，同事从网页和 Word 里复制粘贴，带进来一堆乱七八糟的样式，
把页面布局都搞乱了。想让你做个粘贴清洗的工具。

白名单和一段真实的脏 HTML 在 samples 里，格式 README 里有，别改。

想要的效果：把脏内容粘进左边（或者把 dirty.html 直接读进来），右边立刻出现清洗后的结果，
同时告诉我"扔掉了哪些东西"——哪些标签被删了、哪些属性被剥了、哪些链接被拦了，都要有个清单。

按 samples/allowlist.json 那份白名单来：不在白名单里的标签，要么整段丢掉、要么只留文字，
选一种做法并保持一致（写进 README）。

几件要照顾到的事：

- 内联 style / class / `data-*` / `mso-*` 这些一律不要
- `javascript:` 之类的链接要拦掉，只留文字，或者把 href 去掉，但要提示我
- Word 那种 `<!--[if gte mso 9]-->` 注释块、`&nbsp;` 占位、空 div 嵌套，都要清掉
- 表格和白名单外的标签（比如 img、table）按规则处理，不能漏掉里面的文字
- 净化完之后一定要真的安全：把结果贴回页面不能触发任何脚本

顺便加个"原始 vs 清洗后"的字数/节点数对比，我要贴大段内容试。

别引库、别 npm、别构建，原生 ES module，别用现成的 sanitizer 库。README 里写清楚白名单规则、
丢弃策略、每一类脏东西是怎么处理的。
