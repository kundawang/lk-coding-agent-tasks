# annotool

画布标注与测量工具，网页版。在图上框重点、拉线量距离、写批注，然后把标注导出去。

纯静态、无构建、无依赖。

## 目录

```
samples/annotations.json   一批已有标注（含一条坏的）
samples/tools.json         工具清单
```

## 标注格式

```json
{
  "image": { "width": 1600, "height": 900 },
  "items": [
    { "id": "a-1", "type": "rect", "x": 120, "y": 80, "w": 300, "h": 200, "color": "#e11d48", "note": "这里漏了校验" },
    { "id": "a-2", "type": "polygon", "points": [[10, 10], [200, 40], [180, 220]], "note": "区域" },
    { "id": "a-3", "type": "line", "from": [0, 0], "to": [500, 300], "note": "量一下" },
    { "id": "a-4", "type": "text", "x": 60, "y": 600, "note": "整体偏暗" }
  ]
}
```

**所有坐标都是相对图片原始像素的**，跟窗口大小、缩放级别无关。

## 要做的

- 工具：矩形、多边形（多次点击闭合成形）、直线、文字
- 缩放（滚轮）和平移（空格拖或中键），任何缩放级别下标注的位置都不能飘
- 选中标注能改颜色、改批注、删除；双击文字标注能就地编辑
- 直线要显示长度（像素，并且能输入一个"比例尺"显示成实际尺寸）

## 重点

- **坐标换算**：图上显示的坐标必须是原图像素，跟缩放/平移/窗口大小无关。同一个标注在 100% 和 400% 下拖
  的结果要一致
- 导出的 JSON 要能再导回来，位置一丝不差
- `annotations.json` 里有一条坏数据（坐标越界/点太少），要单独报出来，不能整份加载失败
