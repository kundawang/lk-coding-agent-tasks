我们的任务看板要在三栏之间拖卡片，现在用的东西一拖就乱：松手的位置跟提示的位置对不上，
键盘用户还完全用不了。想让你重做一个。

板子数据在 samples/board.json，格式 README 里有，别改。

要做的：卡片同栏上下拖、跨栏拖、拖到栏的空白处放末尾，拖的时候要有明确的插入位置提示，
而且松手之后的结果必须跟提示一致。有的栏有容量上限，拖满了要拒绝并提示。

松手之后顺序和归属要存住（localStorage 就行），刷新还在；撤销至少 30 步。

两个重点：

一是键盘也要能操作。空格拿起、方向键移动、空格放下、Esc 取消——只支持鼠标是不行的。
拿起之后要能听见/看见当前在第几栏第几位。

二是拖到视口边缘要能自动滚动，不然卡片多了根本拖不到下面去。
拖拽过程中列表不能抖，位置提示不能闪来闪去。

数据里出现重复卡片 id、或者卡片引用了不存在的栏，要能报出来。

别引库、别 npm、别构建，原生 ES module，也别用浏览器的拖拽事件硬扛（那个在移动端和键盘上都不行）。
README 里写清楚你用的拖拽方案、键盘操作的键位、持久化的时机。
