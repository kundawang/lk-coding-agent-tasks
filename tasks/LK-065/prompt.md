我们代码库里有些格式很怪的段落，靠 black 的 `# fmt: skip` 跳过，不想让它动。
最近发现在 if / while / for / with 这种带括号的头部单独放一个 `# fmt: skip`，
跑 black 直接报 InvalidInput，说这块它解析不了。

同一个输入，上一版发布出来的 black 是能格式化通过的，所以这是我们升级之后才遇到的回归。
把注释挪到别的位置能绕过去，但代码库里已经有一堆这种写法了，不想一个个改。

要求：这种头部单独带 fmt: skip 的写法要能正常格式化，输出还得是能跑、能再次格式化的代码；
其它地方的格式化结果别变。改完补上回归测试。
