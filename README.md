# colorlab

颜色工具，网页版。取色、配调色板、查对比度、看色盲模拟。

纯静态、无构建、无依赖。

## 目录

```
samples/palettes.json   几套现有配色
```

## 颜色写法

要能解析这几种，并且能互相转换（不要只认十六进制）：

```
#fff  #ffffff  #ffffff80
rgb(255, 0, 0)  rgba(255, 0, 0, 0.5)
hsl(0, 100%, 50%)  hsla(0, 100%, 50%, 0.5)
```

## 要算的东西

- 相对亮度、对比度（按 WCAG 那条公式）
- 主色/辅助色：从一组颜色里抽出占主导的几个
- 色盲模拟：`protanopia`、`deuteranopia`、`tritanopia`
- 一键生成深/浅两套主题（保证正文对比度 ≥ 4.5）
