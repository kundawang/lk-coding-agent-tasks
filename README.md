# biglist

虚拟滚动列表，网页版。十万行数据，滚起来不能卡，还要能分组、展开、键盘操作。

纯静态、无构建、无依赖。

## 目录

```
samples/dataset.json   数据集结构与行高说明
samples/rows.jsonl     两万行样例数据（真实项目里是十万级）
```

## 数据

```json
{ "id": "r-000001", "group": "华东", "title": "记录标题", "status": "ok", "size": 1234, "updated": "2026-09-24 10:00" }
```

`group` 有十几个取值，列表要按它分组、组头能折叠。

## 要求

- 只渲染看得见的那几十行（自己实现，别引库）
- 行高不一致（标题长的行会换行变两行）时，滚动条长度和位置要还对得上
- 键盘上下键移动选中行，PageUp/PageDown 翻页，Home/End 到首尾，左右键折叠展开分组
- 选中项滚动离开视口再回来之后要保持选中
