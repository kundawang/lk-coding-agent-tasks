# ansiplay

终端输出渲染器，网页版。把带 ANSI 转义序列的日志渲染成终端里的样子。

纯静态、无构建、无依赖。

## 目录

```
samples/session.log   一段真实的终端输出（带颜色、进度条、光标移动）
```

## 要支持的转义序列

| 类别 | 例子 |
|---|---|
| 颜色/样式 | `\e[31m` `\e[1;32m` `\e[38;5;196m` `\e[38;2;255;0;0m` `\e[0m` |
| 光标移动 | `\e[2A` `\e[10C` `\e[5;10H` `\e[s` `\e[u` |
| 擦除 | `\e[2J` `\e[K` `\e[0K` |
| 回车/退格 | `\r` `\b`（进度条靠这个原地刷新） |

## 要做的

- 按**固定列宽的字符网格**渲染（不是简单地把文本贴出来）：能处理光标跳转、覆盖写、擦除
- 颜色要支持 16 色、256 色、24 位真彩
- 宽字符（中文、emoji）占两列，算列宽时要算对，不然整行会错位

## 重点

- 进度条那种 `\r` 原地刷新的场景，最终渲染结果要和真终端里看到的一致
- 非法/不完整的转义序列（`\e[` 后面断了）不能崩，要当成普通字符处理并记一笔
- 一个大文件（几兆）要能流畅渲染，别卡
- 提供一个"只看纯文本"的开关（把转义序列都去掉）
