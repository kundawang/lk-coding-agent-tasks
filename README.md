# qrcode

二维码生成与识别，网页版。自己按标准算，不引库。

纯静态、无构建、无依赖。

## 目录

```
samples/payloads.json   要编码的内容（含中文、长文本、边界长度）
```

## 范围

只需要支持：

- **Model 2** 二维码
- 纠错等级 `L` `M` `Q` `H`
- 字节模式（UTF-8）
- 版本 1~10（够用了）；超出范围要明确报 "内容太长，需要更高版本"

## 要做的

- 输入内容 + 纠错等级 → 画出二维码（Canvas 或 SVG）
- 实现 RS 纠错编码（GF(256) 上的多项式运算）、掩码选择（按标准评分挑最优掩码）、
  格式信息与版本信息的 BCH 编码
- 生成完之后**自己要能解回来**：写一个解码器，把生成的矩阵读回原始内容，两边对上才算真的对

## 重点

- 中文（UTF-8 多字节）、空内容、超长内容、正好卡在容量边界的长度都要处理
- 掩码评分要按标准算，不能随便挑一个（同一份内容换两次生成结果必须一致）
- 生成出来的码要能被手机扫出来（这是最终验收标准）
