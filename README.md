# mdmini

一个小 Markdown 渲染器，网页版。自己写解析，自己保证安全。

纯静态、无构建、无依赖。

## 目录

```
samples/doc.md        一份把各种写法都用上的文档
samples/evil.md       一份带攻击载荷的文档
```

## 要支持的写法

| 写法 | 说明 |
|---|---|
| `#` ~ `######` | 标题 |
| `**粗**` `*斜*` `` `代码` `` | 行内样式 |
| ``` 围栏代码块 ``` | 带语言标注 |
| `-` / `1.` | 无序、有序列表，支持嵌套 |
| `>` | 引用，可嵌套 |
| `\|a\|b\|` | 表格 |
| `[文字](链接)` `![alt](图)` | 链接与图片 |
| `---` | 分隔线 |

## samples/evil.md 里有什么

`<script>`、`onerror=`、`javascript:` 链接、`<iframe>`、注释里藏标签、
未闭合的标签、超大嵌套（几千层）。渲染出来不能执行任何东西，也不能卡死。
