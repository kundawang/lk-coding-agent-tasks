我们录了几段现场音频，格式是 wav，想剪掉开头那点杂音、给结尾加个淡出，再导出给同事。
现在的做法是打开一个很重的桌面软件，就为干这么点事，太不值了。想让你做个网页版的。

样例音频我放了一份在 samples/tone.wav（8kHz 单声道 16bit，两秒），格式说明 README 里有，别改它。

想要的：

拖进来就能看到波形，能滚轮缩放、拖动平移。按住鼠标拖出一个区间，然后能做这几件事：
裁掉区间外、删掉区间、给区间加淡入或淡出。

波形画得要准——放很大之后要能看出单个采样的起伏，不能永远是一团模糊的色块。
采样点多的时候（我们要处理的是几分钟的录音）不能卡，画的时候抽点没关系，但缩放到很近时要还原细节。

淡化要按采样点算，不能只是把音量线性拉一下就算完——用等功率那种（两端衔接听着不跳）也可以，
但你得在 README 里说清楚用的是哪种，并且能看出来淡入淡出是真的写进采样里了。

导出要写成 wav，采样率和声道数跟输入一致，别的软件要能正常打开。导出的文件要能直接下载。

撤销要能用（至少 50 步），退回去之后波形和选区都要跟着回去，别只改了一半。

wav 你自己解析，别引库。8 位、24 位、多声道的文件我也可能丢进去——不支持的话要明确告诉我，
不要画出一团错的东西。

别引库、别 npm、别构建，原生 ES module + Canvas。README 里写清楚支持哪些格式、淡化用的什么算法。
