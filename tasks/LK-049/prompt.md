我们做对账的时候发现过 0.30000000000000004 这种数，财务看了直接不认。想让你做个高精度计算器。

一串表达式和期望结果放在 samples 里，格式 README 里有，别改。

要支持的：加减乘除、括号、幂、取余，还有 sqrt、abs、round、ceil、floor、max、min、sum 这些函数；
能设小数位数和舍入规则（四舍五入和四舍六入五成双都要能选）；支持变量赋值再引用。

三个重点：

一是绝对不能用浮点数算。0.1 + 0.2 必须等于 0.3，0.1 * 3 - 0.3 必须等于 0。
几十位的整数乘法（比如 2 的 200 次方）也要精确。

二是除不尽的时候要诚实。1/3 按当前精度给结果，但界面上必须标明这是近似值，
不能跟精确值混在一起显示。

三是报错要指位置。括号不配对、除零、函数参数个数不对，要告诉我错在第几个字符，
别只弹一句"表达式错误"。

要有历史记录，点历史能再算一次；也要能改精度设置，改完历史结果按新精度重算一遍。

计算核心自己写（有理数或者大整数加定点都行），不许引数学库、不许用 Number 做小数运算。

别引库、别 npm、别构建，原生 ES module。README 里写清楚数值是怎么表示的、舍入规则、
近似值是什么时候产生的。
