我们表单校验现在是每个页面各写一套 if，规则改一下要动好几处，测试也测不全。
想让你做个配置驱动的校验引擎。

规则和一份填错的数据在 samples 里，格式 README 里有，别改。

要支持的规则我列在 README 里了：必填、长度、数值范围、正则、邮箱、网址、
两次输入一致、条件必填、唯一性（假装有个已占用列表），还有"校验不过就不跑后面规则"这种顺序。

三个重点：

一是异步的竞态。唯一性校验是异步的，用户连续改三次，第一次的响应可能最后才回来——
这时候必须把过期结果丢掉，不能让它覆盖新结果。这个我会专门试。

二是错误要一次给全。不能校验到第一个错就停，所有字段的问题要一起显示出来，
对应输入框标红并写清楚原因。

三是规则配置本身写错了（未知规则类型、参数缺失、正则非法）要在加载时明确报出来，
告诉我是哪个字段的哪条规则，别默默跳过。

界面上左边是表单、右边是实时校验结果，加一个"提交"按钮模拟整体校验。

别引库、别 npm、别构建，原生 ES module。README 里写清楚支持哪些规则、异步竞态怎么处理的、规则加载校验怎么做。
