我们每周要处理一批现场照片，统一缩到 1280、加上"内部资料"的水印，再发给客户。
现在是用桌面软件一张张点，太费时间。想让你做个网页版的批量处理工具。

任务配置我放在 samples/jobs.json 了，格式 README 里有，别改。

想要的：

把一批图拖进页面，按配置里的步骤依次处理——自动摆正方向（手机拍的图带 EXIF 方向）、缩放、
裁剪、加水印，右边实时看效果，处理好之后打包下载。

几个我比较在意的点：

- 不能卡界面。几十张几兆的图一起处理，页面要一直能点，进度要看得见，能中途取消；
  concurrency 配置是几就同时处理几张
- 异常要顶住。不是图片的文件、零字节的、宽高是 0 的、文件名重名的、特别大的图，
  都得单独报出来是哪一张、为什么失败，不能让整批停掉，也不能悄悄跳过
- 水印位置是相对比例（0~1），不管图多大都要在同一个相对位置
- 处理前后要能对比看（原图 / 处理结果 并排或者滑动对比）
- 导出文件名按配置里的模板来，重名要自动加序号，不能互相覆盖

顺便给我一个"原图大小 / 导出大小"的汇总，我要看看压缩效果。

别引库、别 npm、别构建，原生 ES module + Canvas。README 里写清楚支持哪些输入格式、各步骤的算法、
失败是怎么隔离的。
