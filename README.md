# cronlab

cron 表达式解析与运行预览，网页版。写个表达式，立刻看到它下一次什么时候跑。

纯静态、无构建、无依赖。

## 目录

```
samples/expressions.txt   一串要能解析的表达式
samples/schedule.json     一个"几点该跑"的对照表，用来验算
```

## 支持的写法

```
分 时 日 月 周
0 3 * * *        每天 3:00
*/15 * * * *     每 15 分钟
0 9-18 * * 1-5   工作日 9 到 18 点整点
0 0 1 * *        每月 1 号
30 4 1,15 * *    每月 1 号和 15 号
```

| 记号 | 含义 |
|---|---|
| `*` | 任意 |
| `a-b` | 区间 |
| `a,b,c` | 列举 |
| `*/n` `a-b/n` | 步长 |
| `?` | 日/周里表示"不指定"（跟 `*` 区分开） |
| 名字 | 月和周支持 `JAN`、`MON` 这种 |

月的取值范围 1~12，周 0~6（0 是周日，7 也当周日）。
