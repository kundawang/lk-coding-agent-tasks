# LK-203 至 LK-205 题目筛选说明

筛选依据为用户提供的《CC/Codex 用户反馈标注（领域专项）项目》要求：题目必须来自真实工程场景，属于安全、游戏/图形与多媒体、数据工程三大领域，难度只能是困难或地狱，并且需要跨模块理解和可观察、可测试的交付结果。

## LK-203

- 领域：安全
- 子方向：其他
- 来源：<https://github.com/netty/netty/issues/17452>
- 上游基线：`bbda2925c6ff3cc425bfc4e114eac8374ed1e145`
- 许可证：Apache-2.0
- 任务类型：Bugfix
- 难度：困难
- 入选理由：默认 HTTP/2 到 HTTP/1.x 适配路径没有在转换前完整验证字段值，属于真实协议安全缺陷；修复涉及 HTTP/2 解码、转换适配器和 HTTP/1 头校验链路。
- 可观察结果：畸形 CR/LF 或其他禁止控制字符必须在转换前被拒绝，合法头和既有显式校验配置不得回归。

## LK-204

- 领域：游戏、图形与多媒体
- 子方向：图形渲染
- 来源：<https://github.com/pixijs/pixijs/issues/12295>
- 上游基线：`1e707686d00a2a8cd6432b047e56034fc7e7a909`
- 许可证：MIT
- 任务类型：Bugfix
- 难度：地狱
- 入选理由：隐藏被 mask 的对象后，stencil mask 继续接收变换并污染复用的 graphics batch，问题横跨 RenderGroup、StencilMask 和 WebGL GraphicsPipe；不同帧、指令集重建与连续动画均有交互。
- 可观察结果：隐藏对象后无关几何应保持像素一致；重新显示对象后 mask 必须恢复；现有 mask 与 RenderGroup 行为不能回归。

## LK-205

- 领域：数据工程
- 子方向：其他
- 来源：<https://github.com/PrefectHQ/prefect/issues/23614>
- 上游基线：`5cf5adc41e7d21f6c32f49a1443ac0441c6fd44c`
- 许可证：Apache-2.0
- 任务类型：Bugfix
- 难度：困难
- 入选理由：异常参数、lone surrogate 或 NaN/Infinity 可在落库后持续破坏 FlowRun、Deployment 和 WorkPool 的筛选与分页接口，涉及 API 校验、事务原子性、Pydantic 模型和读取侧序列化。
- 可观察结果：非法创建请求应返回 422 且不落库；历史脏行不能使整页查询失败；合法参数、标签和 Unicode 数据保持兼容。

## 排除项

- 三题都不属于经典小游戏、Todo、CRUD 或常见模板业务系统。
- 三题均要求理解现有仓库调用链，不能只依赖脱离仓库的纯文本 Prompt 完成。
- 每题只有一个自然语言交付目标，但允许 Agent 在单轮内进行多步搜索、修改和验证。
- 初始快照已删除上游仓库自带的 `AGENTS.md`、`.claude`、`.agents`、`.codex`、`.cursor` 和独立 `SKILL.md` 内容，避免向模型轨迹注入外部 skill。
