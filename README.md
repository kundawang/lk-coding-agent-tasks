# eventreplay

交互录制与回放器，网页版。把我在页面上的操作录下来，之后能一模一样地放一遍。

纯静态、无构建、无依赖。

## 目录

```
samples/recording.json   一段录制（含拖动、输入、滚动、点击、一条放不了的事件）
```

## 录制格式

```json
{
  "startedAt": 1789700000000,
  "events": [
    { "t": 0, "type": "click", "target": "#open", "x": 12, "y": 8 },
    { "t": 420, "type": "input", "target": "#name", "value": "张三" },
    { "t": 900, "type": "drag", "target": "#slider", "from": [20, 10], "to": [140, 10] },
    { "t": 1500, "type": "scroll", "target": "#list", "top": 480 }
  ]
}
```

`t` 是相对录制开始的毫秒数，`target` 是选择器。

## 要做的

- 录制：在页面上操作就记下来（点击、双击、输入、拖动、滚动、按键），生成上面那种 JSON
- 回放：按时间轴放，能暂停、调速（0.5x / 1x / 2x / 4x）、能拖进度条跳到任意时刻
- 拖进度条到中间时，页面状态要是"从头播到这一刻"的结果，不能只是把之前的事件丢掉

## 重点

- 回放要可复现：同一份录制播放两次，结束时页面状态必须一致
- 事件要和目标元素绑得住：回放时元素没了要明确报哪一条事件放不了，然后停下来，不许硬点空白处
- 输入事件要合并（连续敲字合并成一条最终值），不然回放会一个字一个字蹦
- 进度条上能看出每条事件的位置，点一下跳到那条事件
