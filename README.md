# gridcalc

表格公式引擎，网页版。格子能填值也能填公式，改一个格子要能只重算该重算的部分。

纯静态、无构建、无依赖。

## 目录

```
samples/sheet.json   一张工作表：单元格内容
```

## 工作表格式

```json
{
  "name": "预算",
  "cells": {
    "A1": { "raw": "数量" },
    "B1": { "raw": "单价" },
    "A2": { "raw": "12" },
    "B2": { "raw": "3.5" },
    "C2": { "raw": "=A2*B2" },
    "C3": { "raw": "=SUM(C2:C2)*2" }
  }
}
```

`raw` 以 `=` 开头就是公式，否则是字面值（数字或文本）。

## 要支持的公式

| 形式 | 说明 |
|---|---|
| `=A1+B2` | 四则运算 `+ - * /`，括号 |
| `=A1*2` | 数字常量 |
| `=SUM(A1:A9)` `=AVG(...)` `=MIN(...)` `=MAX(...)` `=COUNT(...)` | 区间函数 |
| `=IF(条件, 真值, 假值)` | 条件，支持 `> < >= <= = <>` |
| `=A1` | 引用别的格子（跨表不用做） |

循环引用要能检测出来并标出是哪几个格子绕成一圈，不能卡死。
