# regexlab

正则表达式调试工具，网页版。自己实现一个匹配引擎，把匹配过程一步步画出来。

纯静态、无构建、无依赖。

## 目录

```
samples/cases.json   一组用例：表达式、输入串、期望结果
```

## 要支持的语法子集

| 记号 | 含义 |
|---|---|
| `abc` | 字面量 |
| `.` | 任意一个字符（不含换行） |
| `*` `+` `?` | 重复 0+ / 1+ / 0~1 次 |
| `{m}` `{m,n}` `{m,}` | 重复次数 |
| `[...]` | 字符类，支持 `a-z` 区间与 `^` 取反 |
| `(...)` | 分组，支持 `|` 选择 |
| `^` `$` | 串首 / 串尾 |
| `\d` `\w` `\s` `\.` | 转义类与转义字符 |

## 用例格式

```json
{ "name": "分组与选择", "pattern": "(ab|a)+b", "input": "aab", "expect": true }
```

`expect` 是"能不能匹配上整串/子串"的期望结果，用你实现的引擎跑出来要跟它一致。
