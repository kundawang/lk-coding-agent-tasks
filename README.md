# filterlab

图像滤镜实验台，网页版。自己写卷积，把各种滤镜在一张图上试出来。

纯静态、无构建、无依赖。

## 目录

```
samples/kernels.json   一组卷积核与参数
```

## 核格式

```json
{
  "filters": [
    { "id": "box", "name": "均值模糊", "kernel": [[1,1,1],[1,1,1],[1,1,1]], "divisor": 9 },
    { "id": "sharpen", "name": "锐化", "kernel": [[0,-1,0],[-1,5,-1],[0,-1,0]], "divisor": 1 },
    { "id": "sobel-x", "name": "边缘（横向）", "kernel": [[-1,0,1],[-2,0,2],[-1,0,1]], "divisor": 1, "abs": true },
    { "id": "emboss", "name": "浮雕", "kernel": [[-2,-1,0],[-1,1,1],[0,1,2]], "divisor": 1, "offset": 128 }
  ],
  "presets": { "radius": 1, "gain": 1.0 }
}
```

## 要做的

- 把核应用到图片上（真在像素上算，不是用 canvas 内置的 filter）
- 半径可调（核可以自己生成，比如高斯模糊按 sigma 生成）
- 边缘像素怎么处理要能选：补 0 / 复制边缘 / 镜像
- 灰度、反色、亮度对比度这几个也顺手做上
- 原图 / 处理后能滑动对比

## 重点

- **性能**：一张 4000x3000 的图不能卡死界面（分块处理 + 进度 + 可取消）
- **数值**：超过 0~255 要 clamp，不能溢出成奇怪的颜色；除数为 0 的核要拦住
- 单次滤镜应用前先把原图留一份，撤销要能一步步退回去（至少 10 步）
- 导出处理后的图为 png
