# pathviz

寻路算法可视化对比，网页版。同一张地图上跑几种算法，看谁找的路更好、谁探索得更少。

纯静态、无构建、无依赖。

## 目录

```
samples/maps.json   几张小地图：起点、终点、墙、难走区域
```

## 地图格式

```json
{
  "name": "开阔地",
  "width": 24, "height": 16,
  "start": [1, 1], "goal": [22, 14],
  "walls": [[12, 0, 12, 10]],
  "weights": [[8, 8, 3]]
}
```

`walls` 每项是 `[x1, y1, x2, y2]` 的线段（格子坐标）；`weights` 每项 `[x, y, 代价倍数]`，
表示这个格子走起来更贵。

## 要实现的算法

`BFS`、`Dijkstra`（支持权重）、`A*`（曼哈顿与八向切比雪夫两种启发）、`JPS`（跳点搜索，只在无障碍时用）。

## 要能对比的

- 探索过的格子数、路径长度、路径代价、耗时
- 把探索过程一步步放出来（速度可调、可暂停、可单步）
- 四种算法在同一张图上的结果并排看，路径不一致时高亮差异
- 同一张地图跑两遍结果必须一致（遍历顺序不能受对象键顺序影响）
