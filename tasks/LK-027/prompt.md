我们做界面的时候配色全靠设计师凭感觉给，给完了又发现文字对比度不够、色弱同事看不清。
想让你做个网页版的颜色工具。

现有几套配色在 samples/palettes.json 里，格式 README 里有，别改。

想要的功能：

左边一个取色器（可以输入颜色，也可以从图片里吸色），右边实时看到这颜色配白字和黑字分别是什么效果。
底下把每个颜色的相对亮度、跟白底/黑底的对比度都算出来，达不到 4.5 的明确标红。

几件要照顾到的事：

- 颜色写法不能只认十六进制。`#fff`、`#ffffff80`、`rgb()`、`rgba()`、`hsl()`、`hsla()` 都要能进能出，
  互相转换不能丢精度（尤其带透明度的）
- 对比度按 WCAG 那条公式算，别自己发明。4.5 就是 4.5，不能四舍五入
- 色盲模拟要三种都有（红绿色盲两种、蓝黄色盲一种），点一下能看到这套配色在色弱视角下什么样
- 一键生成深浅两套主题：给一个主色，自动配出背景/正文/次要文字/边框，
  并且保证正文对比度达标；生成出来要能直接导出成 CSS 变量
- 从一组颜色里能抽出"主色"，我要用来做品牌色

导出要能导出成 JSON（色板）和 CSS 变量两段。

别引库、别 npm、别构建，原生 ES module，取色和模拟用 Canvas 就行。
README 里写清楚对比度公式、色盲模拟用的是哪种矩阵、主题是怎么生成的。
