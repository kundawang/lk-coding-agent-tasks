我们的快捷键配置是几个人各改各的，改到最后 Ctrl+S 被两个动作占了，还有人绑了 Ctrl+K 又绑 Ctrl+K S，
按下去到底触发哪个全看运气。想让你做个快捷键编辑器。

动作清单和当前绑定在 samples 里（当前这份是故意有冲突的），格式 README 里有，别改。

要做的：把动作按作用域分组列出来，每个动作能改快捷键。改的时候不要手打字符串——
要能按一下键盘直接识别（按 Ctrl+Shift+S 就录进去），Esc 取消录入。

冲突要当场发现，而且要分清两种情况：完全一样（两个动作都是 Ctrl+S），
和被前缀吃掉（绑了 Ctrl+K，又绑了 Ctrl+K S，按 Ctrl+K 之后不知道是等你继续按还是立刻触发）。
这两种在界面上要用不同提示。

还有几个：

- Mac 和 Windows 要分开配，界面上按平台显示成 ⌘ 或者 Ctrl
- 单键绑定要拦住（比如只绑一个 S），但我能配白名单放行
- 能重置单个动作、重置全部、导出导入这份配置
- 底下加一块"试一试"的区域，按下去告诉我触发了哪个动作

别引库、别 npm、别构建，原生 ES module。README 里写清楚键的表示法、两种冲突怎么判、
平台差异怎么处理的。
