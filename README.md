# themegen

从图片生成配色主题，网页版。丢一张设计稿进去，抽出一套能直接用的颜色变量。

纯静态、无构建、无依赖。

## 目录

```
samples/brand.json   生成规则
```

## 规则格式

```json
{
  "primaryPick": "mostSaturated",
  "neutralSteps": 6,
  "tintSteps": 5,
  "contrast": { "bodyText": 4.5, "largeText": 3.0, "uiBorder": 1.5 },
  "output": { "cssVars": true, "json": true, "tailwind": false }
}
```

## 要做的

- 把图片放进页面，先做颜色量化（中位切分或八叉树都行），把主要颜色抽出来
- 把最抓眼的颜色定为主色（`mostSaturated` 取饱和度最高的，也可以选最常出现的）
- 按主色生成中性的灰阶（跟主色同色相的低饱和色，不是纯灰）
- 按主色调出深浅两套主题，保证正文/次要文字/边框分别达到规则里的对比度门槛
- 导出 CSS 变量和 JSON

## 重点

- 对比度必须真的达标：生成完自己校验一遍，不达标的要说出来
- 同一张图生成两次结果必须一致（量化过程不能受随机种子影响）
- 图片很暗或者几乎单色的时候（比如全黑截图）要能优雅退化，不能生成一堆看不出差别的颜色
- 处理大图（4000x3000）不能卡死，可以先降采样再量化
