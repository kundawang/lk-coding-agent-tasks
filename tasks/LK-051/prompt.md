我们测试同学报 bug 经常描述不清，我让他重现他又忘了当时怎么点的。想让你做个录制回放工具：
把操作录下来，之后能一模一样地放一遍。

一段录制样例在 samples/recording.json（最后一条故意指向了一个不存在的元素），格式 README 里有，别改。

要做的：

录制——在页面上操作就记下来：点击、双击、输入、拖动、滚动、按键，生成那种 JSON。
输入要把连续敲字合并成一条最终值，不然回放会一个字一个字蹦。

回放——按时间轴放，能暂停、能调速（0.5 到 4 倍）、能拖着进度条跳到任意时刻。
拖到中间的时候，页面状态要是"从头播到这一刻"的结果：输入框里得有正确的值、滚动位置也要对，
不能只是把中间那些事件丢掉。

两个重点：

一是可复现。同一份录制播两次，结束时页面状态必须完全一致。
别让状态依赖真实时间的动画，状态变化必须是事件驱动的。

二是事件要绑得住。回放时如果目标元素没了（样例里最后那条就是），
要明确告诉我哪一条事件放不了，然后停下，不许硬往空白处点。

进度条上要能看出每条事件的位置，点一下跳到那条事件；放不了的那条要标成红的。

别引库、别 npm、别构建，原生 ES module。README 里写清楚录制了哪些事件、时间怎么对齐的、
跳转到任意时刻是怎么保证状态正确的。
