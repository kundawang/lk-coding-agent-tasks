我们在做自己的排版组件，浏览器默认的断行规则不够用——行首出现逗号、括号掉到下一行开头、
英文单词被切得七零八落，这些都要我们自己控。想让你写个断行引擎。

规则和几段测试文本在 samples 里，格式 README 里有，别改。

要做的：按给的宽度和字号，把段落排成一行行，并且做这几件事：

- 行首不能出现逗号、句号、右括号这类标点（实在放不下就把前一个字拉下来，或者把标点挤上去）
- 行尾不能出现左括号、左引号这类
- 连续标点（比如。"」）要能挤压到半个字宽，挤压有上限，超了就换行
- 英文按单词断，放不下整体换行；超长单词要按连字符或强制断开
- 中文按字断

每行要给我行宽和挤压用了多少次，我要看排版是不是"刚刚好"。

两个重点：

一是要确定。同样的文本、宽度、字号，排两次结果必须完全一样——不能因为测量顺序或者缓存导致不同。

二是要顶住极端输入：一长串不可断的 A、单个字比整行还宽、空段落、混排的 emoji，
这些都不能崩，也不能死循环。

界面就两栏：左边贴文本改参数，右边实时排版结果，行首行尾的问题用颜色标出来。

别引库、别 npm、别构建，原生 ES module。README 里写清楚断行规则、标点挤压的量、
各条规则之间冲突时谁优先。
