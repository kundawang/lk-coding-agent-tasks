# bigcalc

高精度计算器，网页版。算钱、算比例的时候不能出现 0.30000000000000004。

纯静态、无构建、无依赖。

## 目录

```
samples/expressions.txt   一串表达式
samples/cases.json        期望结果（含精度与近似要求）
```

## 要支持

| 能力 | 说明 |
|---|---|
| 数字字面量 | 整数、小数，超长（几十位）也要准 |
| 运算 | `+ - * /`、括号、`^`（幂）、`%`（取余） |
| 函数 | `sqrt`、`abs`、`round(x, n)`、`ceil`、`floor`、`max`、`min`、`sum(...)` |
| 精度设置 | 小数保留位数；四舍五入规则（四舍六入五成双也要能选） |
| 变量 | `a = 1.1` 然后 `a * 3` |

## 重点

- 不能用浮点数算：`0.1 + 0.2` 必须等于 `0.3`；`1.005 * 100` 要按设置正确取舍
- 超长整数：`2^200`、几十位的乘法要精确
- `1/3` 按当前精度截断/舍入，并且界面上要标明这是近似值
- 表达式写错（括号不配对、除零、函数参数个数不对）要指到出错位置
- 要有历史记录，点历史能再算一次

计算核心自己写（有理数或大整数加定点都行），不许引数学库。
