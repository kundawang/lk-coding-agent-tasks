我们做图像处理的功能，之前用 canvas 自带的 filter，结果一放大就糊、参数也不可控。
想让你自己实现卷积，把常见滤镜做出来。

一组卷积核放在 samples/kernels.json，格式 README 里有，别改。

要做的：把核真的逐像素算上去（不是调 canvas 的 filter）、半径可调（高斯模糊按 sigma 生成核）、
边缘处理可选（补 0 / 复制边缘 / 镜像），再加上灰度、反色、亮度对比度。
原图和处理结果要能滑动对比。

两个重点：

一是性能。一张 4000x3000 的图不能卡死界面——分块算、给进度、能取消。
算的时候页面要还能点。

二是数值要稳。超过 0~255 要 clamp，不能溢出成诡异颜色；除数为 0 的核要拦住；
浮点累加之后再取的整要说明取整方式，别一会儿上取一会儿下取。

撤销至少 10 步（一步步退回原始图），导出的图要能下载。

别引库、别 npm、别构建，原生 ES module + Canvas。README 里写清楚边缘处理三种方式的差别、
核是怎么应用的、性能是怎么保证的。
