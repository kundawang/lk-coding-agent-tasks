# 部署手册

这份文档说明**生产环境**的部署流程，重点看 `deploy.sh` 这个脚本。

## 准备

- 确认配置
- 备份数据库
  - 全量备份
  - 增量备份
- 通知相关同学

## 步骤

3. 上传包
4. 重启服务

```bash
#!/bin/bash
set -e

echo "deploying..."
npm run build
```
