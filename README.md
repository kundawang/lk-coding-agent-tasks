# searchidx

本地搜索索引，网页版。给一堆文档建索引，然后像搜索引擎那样查、能高亮、能按相关度排。

纯静态、无构建、无依赖。

## 目录

```
samples/docs/*.md     十几篇文档
samples/queries.json  几条查询与期望命中的文档
```

## 要实现的东西

- **倒排索引**：词 → 出现过的文档和位置。中文要能切词（按字符二元组就行），英文按空白和标点切、统一小写
- **查询**：单词、多词（and）、短语（引号）、前缀（`前缀*`）、排除（`-词`）
- **排序**：按相关度（tf-idf 或 BM25 都行，选一个并写清楚），相关度相同的按文档名稳定排
- **高亮**：命中片段要返回，前后各留一点上下文，命中的词标出来
- **增量**：改一篇文档只重建它自己那部分，不要全量重来；要能看到"这次更新了几个词条"

## 要顶住的情况

- 十万级词条不能卡（索引是持久化在本地还是重算，你自己定）
- 查询里带正则特殊字符、空查询、只有排除词，都不能崩
