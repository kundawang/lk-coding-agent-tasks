我们做落地页经常要做动画，现在都是手写 CSS 的 keyframes，调一下位置就要算一遍百分比，太烦了。
想让你做个网页版的关键帧编辑器。

场景数据我写在 samples/scene.json 里了，格式 README 里有，别改。

想要的：

上面是预览区，下面是时间轴，每个属性一条轨道，关键帧画成小方块。拖方块能改时间，双击能改值，
选中之后能从下拉里换缓动。时间轴要能滚轮缩放、拖动平移，拖的时候吸附到整数帧（场景里有 fps）。
改完按播放能在预览区真的动起来，能循环、能拖进度条。

缓动不能糊弄——`easeOutCubic` 就是 `1-(1-t)^3` 那个，`easeInOutQuad` 也得对。
我要能对比：把两个缓动叠在同一张曲线图上画出来。

两件我比较在意的事：

一是**导出要能用**。导出成一份 CSS `@keyframes`（百分比按 durationMs 算好）和一份 JSON。
导出的 CSS 我直接贴到页面上要能放出一样的动画，不能差一帧。

二是**撤销**。拖错了要能 Ctrl+Z 退回去，至少 100 步；关键帧拖过界（超出 0~durationMs、或者两个关键帧时间撞一起）
得拦住并提示，不能悄悄改成别的值。

另外关键帧之间不能有时间重叠，同一个属性上时间必须严格递增——我手改 JSON 塞进去乱序的数据，
你得能提示我哪一条有问题，而不是画出来一团乱。

别引库、别 npm、别构建，原生 ES module + Canvas 或 DOM 都行。README 里写清楚怎么开、
缓动的公式、导出格式长什么样。
